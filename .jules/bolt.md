## 2024-05-18 - [Optimize Home Assistant native_value Getters]
**Learning:** Home Assistant evaluates properties like `native_value` and `extra_state_attributes` frequently on the main event loop. Performing O(N) operations (e.g., iterating or filtering lists) directly inside these property getters causes severe performance degradation as the component scales.
**Action:** Extract O(N) calculations into state update methods (like `_handle_coordinator_update` or custom methods called by it). Compute the value when new data arrives, cache it in standard attributes like `_attr_native_value`, and allow the base class to return it in O(1) time.
